# ItemsPlugin

Плагин для **Paper 1.18.2** с графическим управлением кастомными предметами, тегами и личным бесконечным хранилищем.

## Возможности

- создание, изменение и удаление шаблонов предметов;
- выбор любого предметного материала из Minecraft;
- название с цветовыми кодами `&a`, `&6` и т. п.;
- описание предмета;
- настраиваемая максимальная и текущая прочность;
- автоматическое уменьшение прочности кастомного предмета при использовании;
- режим без прочности (`0` в поле максимальной прочности);
- создание и редактирование тегов;
- 13 готовых цветов тегов и произвольный HEX-цвет, например `#33AAFF`;
- добавление нескольких тегов к одному предмету;
- отдельное бесконечное хранилище для каждого игрока;
- постраничное меню хранилища, сортировка, получение и удаление предметов;
- сохранение шаблонов в `plugins/ItemsPlugin/items.yml`;
- сохранение хранилищ в `plugins/ItemsPlugin/storage/<UUID>.yml`.

## Требования

- Paper 1.18.2 или новее;
- Java 17 или новее.

## Установка

1. Соберите проект командой `mvn clean package`.
2. Переместите `target/minecraft-items-plugin-1.1.0.jar` в папку `plugins` сервера.
3. Перезапустите Paper-сервер.
4. Команды создания и изменения доступны операторам через permission `items.admin`.

## Команды

| Команда | Описание | Права |
|---|---|---|
| `/items` | Открыть главное меню | не нужны |
| `/items help` | Показать справку в чате | не нужны |
| `/items create [id]` | Открыть создание предмета | `items.admin` |
| `/items edit <id>` | Открыть изменение предмета | `items.admin` |
| `/items delete <id>` | Удалить шаблон предмета | `items.admin` |
| `/items give <id> [игрок]` | Выдать предмет игроку | `items.admin` |
| `/chest [страница]` | Открыть личное хранилище | не нужны |

## Работа через меню

### Создание предмета

1. Откройте `/items` и выберите **Создать предмет**.
2. Выберите материал.
3. Нажмите поле ID, название, описание или прочность и введите значение в чат.
4. При необходимости выберите несколько тегов.
5. Нажмите **Сохранить**.

ID принимает латинские буквы, цифры, `_` и `-`, длина — от 1 до 32 символов.
Для отмены ввода в чат напишите `отмена`.

### Изменение и удаление

В разделе **Все предметы**:

- ЛКМ по предмету — открыть редактор;
- ПКМ по предмету — удалить шаблон.

Удаление шаблона не удаляет уже сохранённые копии из личных хранилищ.

### Теги и цвета

В разделе **Теги** создайте тег, укажите его ID и название, затем выберите готовый цвет. Для произвольного цвета выберите **Свой HEX-цвет** и введите значение вида `#RRGGBB`.

В редакторе предмета можно выбрать несколько тегов. При изменении цвета тега цвет обновится и в предметах, где этот тег используется.

### Личное хранилище

Хранилище создаётся отдельно по UUID игрока и не имеет ограничения в 54 предмета. 54 — это только количество предметов на одной странице меню.

- **Добавить** — выбрать шаблон и положить его копию в хранилище;
- ЛКМ по предмету — получить копию в инвентарь;
- ПКМ по предмету — удалить копию;
- **Сортировать** — отсортировать по ID;
- стрелки — переход между страницами.

Если инвентарь игрока заполнен, предмет из хранилища не удаляется.

## Прочность

Максимальная прочность и текущая прочность хранятся отдельно у шаблона и у каждой копии в хранилище. При использовании предмета Paper-событие урона перехватывается плагином, поэтому используется именно заданная кастомная прочность.

- `Макс. прочность = 0` — у предмета нет ограничения прочности;
- текущая прочность не может быть выше максимальной;
- сломанный предмет остаётся в инвентаре с прочностью `0` и отображается как сломанный.

## Структура данных

```text
plugins/ItemsPlugin/
├── items.yml
└── storage/
    └── <UUID игрока>.yml
```

Данные сохраняются после изменения и дополнительно при выключении плагина.

# ItemsPlugin - Minecraft Paper 1.18.2

Полнофункциональный плагин для управления кастомными предметами с системой тегов, прочности и персональным хранилищем.

## 🎮 Возможности

### Управление предметами
- ✅ Создание кастомных предметов с собственными названиями
- ✅ Изменение/редактирование существующих предметов
- ✅ Удаление предметов
- ✅ Просмотр всех предметов в меню

### Система тегов
- ✅ Создание тегов с разными цветами
- ✅ Привязка тегов к предметам
- ✅ Изменение цвета тегов
- ✅ Удаление тегов

### Управление прочностью
- ✅ Установка максимальной прочности
- ✅ Отслеживание текущей прочности
- ✅ Добавление урона предметам
- ✅ Ремонт предметов
- ✅ Процент прочности

### Персональное хранилище
- ✅ Бесконечный сундук для каждого игрока (54 слота)
- ✅ Добавление/удаление предметов
- ✅ Сортировка предметов
- ✅ Сохранение данных при выходе

## 🎮 Команды

| Команда | Описание |
|---------|----------|
| `/items` | Откр��ть главное меню управления |

| `/items help` | Справка по плагину |
| `/chest` | Открыть персональное хранилище |

## 🖱️ Использование

### Через графический интерфейс (GUI)
1. Введите `/items` для открытия главного меню
2. Выберите нужную опцию:
   - **Мои предметы** - просмотр всех предметов
   - **Создать предмет** - создание нового предмета
   - **Управление тегами** - работа с тегами
   - **Персональное хранилище** - открыть сундук
   - **Справка** - информация о плагине

### Создание предмета
1. Перейдите в меню создания предмета
2. Выберите материал
3. Установите имя предмета
4. Укажите максимальную прочность
5. Добавьте теги
6. Сохраните предмет

### Работа с хранилищем
1. Введите `/chest`
2. Предметы отображаются в 54 с��отах
3. Можно добавлять и удалять предметы
4. Данные автоматически сохраняются

## 📦 Установка

### Требования
- Paper 1.18.2 или новее
- Java 17+

### Установка
1. Загрузите JAR файл в папку `plugins/`
2. Перезагрузите сервер
3. Плагин готов к использованию!

```bash
java -jar minecraft_server.jar nogui
```

## 🎨 Особенности

### Теги с цветами
Каждый тег имеет:
- Уникальный ID
- Название
- Цвет (RGB формат)
- Отображение в hex формате (#RRGGBB)

### Прочность предметов
- Максимальная прочность настраивается
- Текущая прочность отслеживается
- Процент прочности рассчитывается автоматически
- Наглядное отображение в чате

### Бесконечное хранилище
- 54 слота на игрока
- Автоматическое сохранение
- Привязка к UUID игрока
- Не зависит от инвентаря игрока
